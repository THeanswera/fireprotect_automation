# Аудит формул Excel

Объект аудита: локальная книга `01_Общая ОБМ — копия.xlsx`, SHA-256
`20e164da4d43d05510e76474fdc8c566dff9e585332b4032f6efca039a022360`.
Наличие формулы в книге не считается доказательством её нормативной или
технической корректности.

## Классы

- **A — математическая/геометрическая:** тождество проверяется из размерностей
  и явно заданной геометрии, без нормативной таблицы.
- **B — технические данные:** формула читает или использует таблицу конкретного
  огнезащитного материала. Первичный технический документ обязателен.
- **C — нормативная:** формула непосредственно реализует нормативное правило.
- **D — служебная:** индекс, ссылка, сумма или представление результата; сама
  по себе не назначает инженерный параметр.
- **E — неизвестная:** смысл коэффициента или правила пока не доказан.

## Полная классификация 579 формул

| Класс | Количество | Формулы/ячейки | Вывод |
|---|---:|---|---|
| A | 264 | `I=P/Q/S/AB/AC`, строки `6:49` | количество, периметр, A/P, длина и площадь; совпадение с Python проверено, нормативная применимость контура отдельно не доказана |
| B | 132 | `Y`, `AF`, `AG`, строки `6:49` | толщина, удельный и общий расход зависят от листов технических данных |
| C | 0 | — | нормативных формул, однозначно доказанных первичным источником, в книге не выявлено |
| D | 180 | `U/V/AD/AE` (`176`), `K1/K2/AC50/AG50` (`4`) | индексы `MATCH`, ссылки и итоговые суммы |
| E | 3 | `AC51`, `AC52`, `AG51` | коэффициенты `1,2` подписаны неоднозначно и не имеют доказанного основания |
| **Итого** | **579** | — | совпадает с OOXML и `calcChain.xml` |

### Класс A

Для каждой строки `r=6…49`:

- `I=G×H`;
- `P=2×h+4×b−2×s` либо `P=2×b+2×h` в зависимости от сохранённой семьи
  профиля;
- `Q=P` — математически простая ссылка, но само решение о полном обогреве
  является инженерным и книгой не обосновывается;
- `S=R×100/Q`, где `R` — площадь сечения в см², `Q` — мм;
- `AB=I×J`;
- `AC=AB×Q/1000`.

Эти тождества воспроизведены модулем `fireprotect.geometry`. Python не
принимает `Q=P` по умолчанию: обогреваемый контур и его основание задаются
явно.

### Классы B и D

`U/V` и `AD/AE` являются только индексами. Инженерные результаты создают:

```text
Y  = INDEX(Толщина ОЗ, MATCH(ПТМ, ..., 1), MATCH(R, ..., 0))
AF = INDEX(Расход ОЗ,  MATCH(ПТМ, ..., 1), MATCH(R, ..., 0))
AG = AC × AF
```

`MATCH(...,1)` выбирает последнее значение ПТМ, не превышающее расчётное; это
ступенчатый поиск без интерполяции. Ни Excel, ни его кэш не являются первичным
источником значений `Y/AF`.

## Идентификация материала и первичного источника

Вторичный локальный документ
`Примеры/021_ПЗ_Огнезащита.docx` (SHA-256
`8f4e7520fd1c7bfbf853d6dd8a75ef55ec9480eedffb23fb61c42f0479ee5edd`)
называет систему **«ОБМ-Мет»**, базальтовый материал **«ОБМ-Ф»** и клеевой
состав **«EXPERT Standart»**. Он также приводит таблицу 9.1 для ПТМ
`2,4…11,0` и R15/R45/R60/R90.

Это проектная пояснительная записка, а не первичный технический документ. В
рабочем каталоге не найдены заявленные ТУ, протокол испытаний, технический
регламент производителя или оригинал сертификата. База `rx3/fpm.rxdb`
содержит только два демонстрационных материала и не содержит «ОБМ-Мет», ОБМ,
EXPERT или DEFENDER.

Статус таблиц: **UNVERIFIED_TECHNICAL_DATA**.

### Обнаруженное расхождение

Для ПТМ `3,4…11,0` и R90 вторичный документ указывает толщину `10 мм`, тогда
как Excel возвращает `8 мм`. Колонка R120 (`16 мм` при ПТМ `2,4…3,3`, `10 мм`
при `3,4…11,0`) во вторичном документе не найдена. Автоматически выбирать
правильное значение запрещено; расхождение требует первичного документа и
решения инженера.

## Лист `ТР`

Формул на листе нет, а ссылка из расчётных строк отсутствует. Первичный
нормативный источник и условия применимости матрицы не установлены. Поэтому
значение R из `ТР` не переносится автоматически; оно задаётся объектом
`RequiredFireResistanceDecision` и до подтверждения инженером имеет статус
`NEEDS_ENGINEER_CONFIRMATION`.

## Правила использования

1. Формулы A можно использовать как проверяемые тождества только при явно
   заданной геометрии и схеме обогрева.
2. Формулы B нельзя переносить на другой материал и нельзя считать
   верифицированными до регистрации первичного документа.
3. Формулы C отсутствуют; нормативное назначение R не автоматизировано.
4. Формулы D не являются самостоятельным инженерным доказательством.
5. Формулы E блокируют автоматическое формирование итоговой спецификации.

## Release status

Созданная книга имеет вид `EXCEL_COMPATIBILITY_EXPORT`, а canonical project
data остаются в `ProjectElement` и audit. Copy-only writer сохраняет исходник,
ZIP parts и точную карту 579 формул, но не выполняет формулы. До фактического
открытия, полного пересчёта и сохранения в Microsoft Excel результат имеет
`EXCEL_RECALCULATION_REQUIRED` и блокирует production issue.

Production дополнительно требует зарегистрированный SHA-256 версии Excel
template и `VERIFIED_TECHNICAL_DATA` с первичным документом производителя.
Листы `Толщина ОЗ` и `Расход ОЗ`, пояснительная записка и `fpm.rxdb` сами по
себе не являются таким доказательством.
