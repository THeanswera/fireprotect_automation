# Нормативная прослеживаемость

Собственные нормативные расчётные формулы пока не реализованы. Поэтому ни
одному результату не присваивается статус нормативно верифицированного.
Программный контракт `NormativeTrace`/`NormativeResult` уже реализован в
`fireprotect.normative`: production-проверка отклоняет результат без trace,
а исследовательский режим обязан быть выбран явно.

## Обязательный контракт

Каждый будущий нормативный результат должен нести один или несколько `NormativeTrace`:

```python
@dataclass(frozen=True)
class NormativeTrace:
    document_id: str
    edition: str
    clause: str
    formula_or_table: str | None
    description: str
```

`document_id` обязан ссылаться на запись из `normative/registry.yaml`. В production-режиме запрещено вычислять нормативный результат, если:

- документ имеет статус `IDENTIFICATION_REQUIRED` или `EDITION_VERIFICATION_REQUIRED`;
- не указаны пункт и редакция;
- формула/таблица не указана там, где результат от неё зависит;
- SHA-256 фактического файла отличается от реестра.

## Текущая матрица

| Результат | Ожидаемый источник | Состояние |
|---|---|---|
| Геометрия профиля RX3 | `rx3.rxdb` | CONFIRMED как данные RX3; не нормативный расчёт |
| ПТМ и section factor из RX38 | тождества A/P и P/A + отчёт RX3 | CONFIRMED как семантика RX38; нормативная методика ещё не заявлена |
| Критическая температура из RX38 | результат RX3 / EN-модель, выбранная в RX3 | Значение читается; независимая нормативная верификация НЕ ВЫПОЛНЕНА |
| Собственный предел огнестойкости | результат RX3 | Значение читается; независимая нормативная верификация НЕ ВЫПОЛНЕНА |
| Сочетания нагрузок | СП 20.13330.2016, применимая редакция | НЕ РЕАЛИЗОВАНО |
| Расчёт стали | СП 16.13330.2017, применимая редакция | НЕ РЕАЛИЗОВАНО |
| Толщина огнезащиты | техническая документация конкретной системы | НЕ РЕАЛИЗОВАНО |
